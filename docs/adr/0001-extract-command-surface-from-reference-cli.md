# Extract the command surface from the Reference CLI instead of hand-writing commands

The Reference CLI has ~175 services and ~9,400 Leaf commands, generated from the OCI Python SDK into ~660k lines of Click code, with ~62k lines of hand-written overrides layered on at import time. There is no standalone spec. We extract one: import the pinned Reference CLI, walk its final Click tree (after overrides), join each Leaf command to its SDK operation, and commit the result as data that a generic boci engine executes. A Leaf command whose callback lives outside the generated modules is classified as a Custom command and requires hand-written boci code. Hand-writing every command was rejected as impossible to finish and impossible to keep in sync with Reference CLI upgrades.
